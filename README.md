
# 🐍 Snake n’ Crunch

**Snake n’ Crunch** is a beginner-friendly version of the classic Snake game built with **Python** and **Pygame**.

Guide the snake, eat apples, grow longer, and avoid hitting yourself! Includes music, sound effects, and a Windows `.exe` version.

---

## 🎮 How to Play

- Use **Arrow Keys** to move the snake
- Eat the apple 🍎 to grow
- Avoid crashing into yourself
- Press **Enter** to restart after game over, or **Esc** to exit
- The snake can move through walls (no wall collision)

---

## ⚙️ Requirements

Install Python dependencies using:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run from Source

```bash
python Snake.py
```
